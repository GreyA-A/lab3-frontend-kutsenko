# Лабораторна робота №3. JavaScript (Варіант 4)

Дисципліна: «Розробник фронтенду програмних систем».
Тема: основи, функціональне та об'єктно-орієнтоване програмування мовою JavaScript.

## Завдання
1. **Курси** (масиви, методи масивів, функції): сортування за тривалістю
   та середня кількість користувачів, пошук мінімуму за добу_2, додавання
   запису залежно від повноти даних, тривалість одночасного вивчення курсів.
2. **Облікові записи дітей** (ООП): фільтр за місяцем і часом, мінімальний вік,
   поділ за віковими класами, сортування за E-mail.

## Структура
- `lab3.html` — сторінка, що підключає скрипти
- `js/task1-courses.js` — завдання 1
- `js/task2-children.js` — завдання 2

## Запуск
Відкрити `lab3.html` у браузері, натиснути `F12` і перейти на вкладку
«Консоль» — там виводяться результати обох завдань.
